​                                                                                                                                  查     增        改      删        改（部分）

@GetMapping("/login")/@PostMapping("/login")/@PutMapping("/login")/@DeleteMapping("/login")等等

总结：

1. `@RequestMapping` 支持精准（固定路径）/ 模糊（*/**）两种路径匹配，精准匹配是开发主流；
2. 类级别 + 方法级别注解结合，可分层管理请求路径，简化配置；
3. 可通过 `method` 属性限制请求方式，不匹配会抛出 405 异常，优先使用 @GetMapping 等快捷注解；
4. 需保证「路径 + 请求方式」组合唯一，否则会触发映射冲突异常。

@RequestParam("name") String name, 
@RequestParam("stuAge") int age

http://localhost:8080/param/data?name=张三&stuAge=18



一名多值参数@RequestParam List<String> hbs

总结：

1. 直接接收参数：简单但灵活性低，需注意 “基本类型不能接收 null” 的坑；
2. `@RequestParam`：解决参数名不一致、必传控制、默认值设置等问题，是开发中最常用的参数接收注解；
3. 实体类接收：参数较多时优先使用，需保证属性名与参数 key 一致；
4. 一名多值接收：用 List / 数组接收多选类参数。`@RequestParam`可选。

将上述文档中涉及的全部 Spring Boot / Spring MVC / Jakarta Validation 注解整理并进行系统分类，附带具体用法与适用场景：



### 一、 三层架构与组件管理注解 (IoC)

此类注解用于告诉 Spring 核心容器：“将该类交由你来托管与创建对象（实例化）”。  



| **注解**              | **适用层级/位置**             | **作用与用法说明**                                           |
| --------------------- | ----------------------------- | ------------------------------------------------------------ |
| **`@Component`**      | 通用类/工具类                 | **通用组件注解**。用于非三层架构中的类（如工具类、拦截器类），标记后加入 Spring 容器管理。 |
| **`@Repository`**     | 数据访问层 (`DAO` 实现类)     | **数据持久层组件注解**。标注在 DAO 实现类上，语义化标识数据访问组件，并交由 Spring 容器管理。 |
| **`@Service`**        | 业务逻辑层 (`Service` 实现类) | **业务层组件注解**。标注在 Service 实现类上，语义化标识业务逻辑组件，并交由 Spring 容器管理。 |
| **`@Controller`**     | 表现层/控制器                 | **表现层控制器注解**。标注在 Controller 类上，用于传统 Web 混合开发（配合视图渲染跳转页面）。 |
| **`@RestController`** | 表现层/控制器                 | **RESTful 控制器组合注解**。等价于 `@Controller` + `@ResponseBody`，标注后类中所有方法默认返回 JSON 格式数据（前后端分离首选）。 |

### 二、 依赖注入注解 (DI)

此类注解用于将 Spring 容器中已创建好的组件或属性“送/注入”到目标对象的变量中，替代手动 `new`。  



| **注解**         | **适用位置**                 | **作用与用法说明**                                           |
| ---------------- | ---------------------------- | ------------------------------------------------------------ |
| **`@Autowired`** | 成员变量 / setter / 构造方法 | **Spring 原生按类型注入**。默认根据接口/类**类型**自动寻找匹配组件并注入。支持设置 `required = false` 规避空指针报错。 |
| **`@Qualifier`** | 成员变量 / 形参              | **配合 `@Autowired` 精准指定 Bean 名称**。当一个接口有多个实现类时，用 `@Qualifier("beanName")` 避免类型冲突。 |
| **`@Resource`**  | 成员变量 / setter            | **JDK 原生按名称注入**。默认优先按**组件名称**注入，支持指定名字 `@Resource(name="userDaoImplV2")`，适合多实现类场景。 |

### 三、 配置文件属性注入注解

此类注解用于将 `application.properties` 或自定义外部 `.properties` 文件中的参数读取并赋值给变量。  



| **注解**                       | **适用位置**        | **作用与用法说明**                                           |
| ------------------------------ | ------------------- | ------------------------------------------------------------ |
| **`@Value`**                   | 成员变量 / 方法形参 | **读取单个配置项**。语法：`@Value("${key:默认值}")`。例如 `@Value("${app.port:8080}")`。 |
| **`@ConfigurationProperties`** | 类                  | **批量绑定同前缀配置**。搭配 `@Component` 使用，指定前缀 `prefix = "db"`，自动将属性与配置项映射赋值。 |
| **`@PropertySource`**          | 类                  | **加载自定义外部配置文件**。例如 `@PropertySource(encoding = "UTF-8", value = "classpath:config/db.properties")`。 |

### 四、 HTTP 请求映射与 REST 快捷注解

此类注解用于将客户端请求的 URL 路径映射到 Controller 对应的处理方法（Handler）上。  



| **注解**              | **适用位置** | **作用与用法说明**                                           |
| --------------------- | ------------ | ------------------------------------------------------------ |
| **`@RequestMapping`** | 类 / 方法    | **通用路径映射注解**。可标注在类上统一前缀（如 `@RequestMapping("/user")`）；默认支持所有 HTTP 请求方式（可加 `method` 参数限制）。 |
| **`@GetMapping`**     | 方法         | **GET 请求快捷注解**。等价于 `@RequestMapping(method = RequestMethod.GET)`，专用于**资源查询**。 |
| **`@PostMapping`**    | 方法         | **POST 请求快捷注解**。等价于 `@RequestMapping(method = RequestMethod.POST)`，专用于**新增资源**。 |
| **`@PutMapping`**     | 方法         | **PUT 请求快捷注解**。等价于 `@RequestMapping(method = RequestMethod.PUT)`，专用于**修改/全量更新资源**。 |
| **`@DeleteMapping`**  | 方法         | **DELETE 请求快捷注解**。等价于 `@RequestMapping(method = RequestMethod.DELETE)`，专用于**删除资源**。 |
| **`@PatchMapping`**   | 方法         | **PATCH 请求快捷注解**。等价于 `@RequestMapping(method = RequestMethod.PATCH)`，专用于**资源部分更新**。 |

### 五、 请求参数接收与绑定注解

此类注解用于从 HTTP 请求的各种位置（URL 参数、路径、请求体、请求头）提取数据并绑定到方法形参。  



| **注解**             | **适用位置** | **作用与用法说明**                                           |
| -------------------- | ------------ | ------------------------------------------------------------ |
| **`@RequestParam`**  | 方法形参     | **绑定 URL QueryString 参数**。支持重命名参数、设置非必填与默认值。如：`@RequestParam(value="name", required=false, defaultValue="guest")`。绑定数组/List 时必须使用。 |
| **`@PathVariable`**  | 方法形参     | **绑定 URL 动态路径参数**。配合 RESTful 路径使用，如 `@GetMapping("/{id}")`，形参写 `@PathVariable Long id` 接收。 |
| **`@RequestBody`**   | 方法形参     | **接收请求体 JSON 数据**。用于 POST/PUT 请求，将请求体中的 JSON 字符串反序列化为 Java 对象。 |
| **`@RequestHeader`** | 方法形参     | **绑定 HTTP 请求头字段**。用于获取 Header 中的令牌或参数，如 `@RequestHeader("Authorization") String token`。 |

### 六、 数据校验注解 (Jakarta Bean Validation)

此类注解标注在实体类（Entity/DTO）属性上，用于在入参到达业务层前校验数据的合法性。  



| **注解**                    | **适用属性类型**      | **校验逻辑与用法说明**                                       |
| --------------------------- | --------------------- | ------------------------------------------------------------ |
| **`@NotNull`**              | 任意类型              | 不能为 `null`（但空字符串 `""` 会通过）。常用于数值、对象、路径 ID 参数。 |
| **`@NotBlank`**             | String 字符串         | **只能用于字符串**。校验不能为 `null` 且去除首尾空格后长度必须大于 0。 |
| **`@NotEmpty`**             | 字符串/集合/数组/Map  | 不能为 `null` 且元素个数/长度大于 0（字符串不去首尾空格）。  |
| **`@Size`**                 | 字符串/集合/数组      | 校验长度范围。如：`@Size(min = 2, max = 20, message = "长度需在2-20位之间")`。 |
| **`@Pattern`**              | String 字符串         | **正则表达式校验**。如校验手机号：`@Pattern(regexp = "^1[3-9]\\d{9}$")`。 |
| **`@Min` / `@Max`**         | 数值类型 (int/Long等) | 校验数值的最小/最大边界值。如：`@Min(0)`、`@Max(1)` 限制范围。 |
| **`@Digits`**               | 数值类型              | 限制整数位与小数位的最大位数。如 `@Digits(integer=3, fraction=2)`。 |
| **`@Past` / `@Future`**     | Date / 时间类型       | `@Past` 限制必须为过去的时间；`@Future` 限制必须为未来的时间。 |
| **`@Valid` / `@Validated`** | 方法形参 / 嵌套属性   | **开启/触发参数校验**。标注在 Controller 形参对象前（如 `@Valid @RequestBody UserDTO dto`）触发对象内部注解校验。 |

### 七、 配置类与全局处理扩展注解

此类注解用于进行全局增强处理，如拦截器注册、全局异常捕获等。  



| **注解**                    | **适用位置** | **作用与用法说明**                                           |
| --------------------------- | ------------ | ------------------------------------------------------------ |
| **`@Configuration`**        | 类           | **标识该类为 Spring 配置类**。等价于传统 XML 配置文件，通常配合 `WebMvcConfigurer` 注册拦截器/跨域设置等。 |
| **`@ComponentScan`**        | 类/启动类    | **手动指定包扫描路径**。指定 Spring 扫描哪些包下的组件注解（如 `@ComponentScan({"com.a", "com.b"})`）。 |
| **`@ResponseBody`**         | 类 / 方法    | **标识返回值直接写入响应体**。跳过视图解析，将返回值通过 JSON 消息转换器格式化后输出给前端。 |
| **`@RestControllerAdvice`** | 类           | **全局异常处理与切面增强**。等价于 `@ControllerAdvice` + `@ResponseBody`，用于捕获整个项目中 Controller 层抛出的异常。 |
| **`@ExceptionHandler`**     | 方法         | **匹配并处理指定异常**。配合 `@RestControllerAdvice` 使用。例如 `@ExceptionHandler(Exception.class)` 处理兜底全局异常。 |
